# 可选消息集成

飞书登录、组织同步、通知和查询机器人均需使用自己的自建应用。占位配置见 .env.example 和 server/.env.example；实际凭据不应进入仓库。

- OAuth 回调与前端地址必须指向自己的部署。演示登录和机器人默认关闭。
- 配置组织根部门、审批人、收件人及群标识后才启用相应业务；代码中的示例名称不是真实通讯录。
- 通常周五 14:00 提醒任务关键进展，16:00 提醒负责人周报。周五休息时改为当周最后一个工作日，整周无工作日不提醒。
- 周报截止为下周一 09:00；领导汇总附于工作日 09:00 日报，成功后按周去重。假期延后发送不改变正式提交状态。
- 修改草稿不发送审批通知；送审及审批结果使用持久化队列。测试应使用桩或独立测试应用，不连接实际业务收件人。
- 可选模型功能默认关闭，启用后数据会传给所配置的模型服务。
