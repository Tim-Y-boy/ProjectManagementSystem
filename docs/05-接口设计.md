# 接口概览

接口前缀为 /api，使用 JWT 鉴权。Controller 角色守卫与 Service 的人员关系、状态、只读和版本校验共同生效。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /project-weekly-reports | 按 weekStart、projectId、deptId、ownerId、status 筛选；allWeeks 与 projectId 一起查历周 |
| GET | /project-weekly-reports/detail | projectId、weekStart 定位详情 |
| GET | /project-weekly-reports/todo | 当前填报人的待提交记录 |
| GET | /project-weekly-reports/updates | 正式周报版本摘要 |
| PUT | /project-weekly-reports/save | 保存草稿 |
| POST | /project-weekly-reports/submit | 校验后正式提交 |
| PUT | /project-weekly-reports/amendment-draft | 保存独立修改稿 |
| POST | /project-weekly-reports/request-amendment | 送审具体修改内容 |
| POST | /project-weekly-reports/review-amendment | 配置的审批人通过或退回 |

正文含 projectId、weekStart、version、overallStatus、achievements、risks、coordination、nextWeek。送审修改另传 draftVersion 和 reason；退回必填 comment。参数错误 400，越权 403，不可见详情 404，版本或审批状态冲突 409。

其他完整接口见 server/src/modules 下的 controller；客户端调用见 web/src/api。接口成功响应不代表外部消息已送达。

## 项目资料及版本接口

- GET /tasks/:id/project-assets：列出同项目可复用资料。
- GET /tasks/:id/assets/:assetId/versions：返回 versions、affectedTasks、canUpdate；版本包含 isCurrent 和 fileAvailable，缺失文件不可下载。
- POST /tasks/:id/assets/:assetId/versions：上传替换文件及 expectedVersionId；单文件最大 50 MB，reason 可选。过期版本返回 409。
- GET /tasks/:id/assets/:assetId/versions/:versionId/download：下载指定不可变版本。
- POST /tasks/:id/progress-save：原子保存正文、上传文件、链接及同项目 existingAssetIds。
- 新增重名返回 409 / TASK_ASSET_DUPLICATE_NAME；桌面客户端可选择内联提示，其他业务错误仍按原机制处理。

使用 node dist/main.js 启动后端前，源码修改须先执行 npm run build；仅重启不会重新编译。新功能还需核对数据库迁移是否执行。
