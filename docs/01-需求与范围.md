# 功能范围

本说明仅描述通用能力，不包含实际组织配置或业务记录。

- 项目计划、层级任务、多负责人、计划定稿和变更审批。
- 任务进展、资料上传、共享附件、工作日期与提交时间分别记录。
- 任务执行、验收、退回，项目结项、终止与重新开启。
- 负责人周报自动保存草稿、主动提交、提交后修改审批。整体状态、本周成果及下周安排为提交必填项。
- 工作日历决定应填周次及提醒日期；全部有效叶子任务完成且完成日期明确时保留完成周，后续等待结项的周次不再强制填报。
- 权限根据角色、项目人员关系及只读状态共同决定；示例数据不对应真实人员。
- 手机端日期独占一行，切周按钮并排，筛选两列；桌面保留详情双栏。

## 资料版本与交互

- 同项目资料可跨任务、跨进展关联，关联任务自动使用最新版，旧文件保留在版本历史中。
- 更新只需上传新文件，无需更新说明；新上传同名文件提示优先关联已有资料、更新已有文件或修改文件名，明确更新不受新增重名检查阻止。
- 桌面重名错误在表单顶部持续显示红字并保留草稿。全部资料在进展下方折叠展示，类型筛选为全部、文件、链接；版本号位于文件名旁。
- 进展中的文件操作收在省略号菜单；全部资料直接显示更新、版本历史、下载和删除，按权限展示。
- 结项报告固定生成时文件版本，后续更新不改写历史报告。
