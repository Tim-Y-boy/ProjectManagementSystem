# 系统使用说明书

更新日期：2026-10-27。适用：当前本地实现；实际可用功能以管理员发布版本为准。

## 一、登录与入口

通过公司提供的系统地址或飞书工作台打开。电脑浏览器使用飞书网页授权；支持的飞书手机环境尝试端内免登，失败时可走网页授权。手机和电脑使用同一账号权限。公司内网地址在外网能否打开取决于网络接入，机器人可回复不代表网页一定可访问。

成员资料和部门来自飞书，系统不单独提供员工注册。账号未同步、停用或权限不符时联系管理员。Mock 登录仅用于本地调试。

常用入口为项目总览、我的待办、审批管理、项目管理、任务管理和结项管理；有权用户还可以查看工作日报。审批管理统一处理任务确认/验收、计划变更、结项和重开，权限按各业务规则判断。管理员还维护用户权限、节假日等配置。

## 二、项目与任务

项目可以指定多名项目负责人；具体任务可以指定多名执行人和验收负责人。项目负责人管理项目，任务负责人负责验收，两者不等同。

项目先排计划，再定稿。未定稿不能开始任务或填写进展；定稿后可以执行，调整日期、人员、任务结构或顺序须发起变更。只有管理员可以解除定稿。

任务可以有多级子任务。具体工作在叶子任务上执行，父任务由子任务汇总。进度由状态计算：待办 0%、进行中 50%、待验收 90%、已完成 100%；父任务按子任务汇总，不需要手填百分比。

## 三、填写进展与资料

1. 打开任务详情，进入“进展与资料”。任务须已开始；已完成且项目仍可编辑的任务也可补资料。
2. 选择真实工作日期，填写关键进展，最多 800 字。
3. 上传文件、粘贴链接、选择飞书文件，或点击“关联已有文件”选本任务已有资料。
4. 本条没有资料时，填写无资料原因；有资料或原因后保存。

工作日期表示哪天做的，填报时间表示哪天录入系统，两者分别保留。可以一天记录多条进展，不要为了通过检查虚填工作日期。

单文件最大 50 MB，每次最多 30 个文件、合计 200 MB。同一任务的不同进展可关联同一份文件，资料总数不会重复累计。解除关联只移除当前进展的引用，不删除文件或其他进展的引用。

编辑已有进展时点击该记录的“编辑”。电脑双栏中左侧表单保持可见，较长表单可内部滚动；窄屏会定位到编辑区。文本框随内容增高。编辑、删除及合理补填按钮会根据身份、记录状态和任务状态显示或禁用。

## 四、每周记录与验收

系统以北京时间周一至周日划分周次。每个需记录的具体任务，每周至少一条非空进展；任一合法提交人填写后即可满足该任务该周，不需要每位执行人重复写。

系统按规则启用后的实际进行中区间检查，与工作日相交的每周至少有一条进展。计划日期不会产生应填周次，也不会截断延期执行。周五 14:00 提醒，节假日跳过；提交验收和验收通过时立即检查，包含本周，不依赖提醒是否发送。等待验收不新增周次，退回后重新计入。

出现缺填提示时，按列表补齐真实工作记录，再提交。待验收任务若发现缺填，先由验收人退回后补充。系统同时要求有有效资料或无资料原因；已在进展中填写的原因可自动带入验收说明。

流程为：待办 → 开始 → 填写进展和资料 → 提交验收 → 验收通过。验收人可退回并说明原因。已完成任务要退回进行中，仅管理员或总经办负责人可操作，且须填写原因。

## 五、补填、合理补填和延期

| 显示 | 含义 |
|---|---|
| 补填 | 记录在工作日之后录入，不等于已认定工作延期 |
| 合理补填 | 有权限的人确认：工作日期在截止内，原提交日期晚于截止；确认原因可选，最多 4000 字 |
| 延期完成 | 当前完成分类依据截止、系统验收日期及合理补填记录计算；查看详情核对工作日期和提交时间 |
| 依据不完整 | 日期等资料不足，不能直接判断按期 |

工作日期晚于截止不能确认为合理补填；截止前或当天提交无需确认。管理员也不能绕过日期条件。一条合理补填不会自动覆盖其他不符合条件的进展。历史不符合当前规则的标记保留核查记录，不自动等同于整个任务合理补填。

合理补填确认后会通知总经办知晓；“我已知晓”表示看过告知，不是再次审批。系统验收晚、填报晚与实际工作晚应分别核查，不据单个日期直接作人员评价。

## 六、计划变更

项目定稿后，在项目处点击“发起变更审核”，可一次调整多个任务，说明变更原因。

- 项目负责人发起：进入总经办终审。
- 其他有权发起人：先经项目负责人，再到总经办终审。
- 只有最终通过后，计划才生效。预审通过不代表日期已经修改。
- 申请人可撤销待审申请；被退回后查看意见再处理。

多项目负责人均参与相应权限判断。不要把任何领导都当作该申请的终审人，页面只向有权处理的人显示操作。

## 七、申请结项与报告

项目负责人或管理员可以申请结项。项目须已定稿、有效任务全部完成、无待审批计划变更，且未归档/未处于结项审批中。没有结项按钮时先检查这些条件，不只看父任务百分比。

填写背景、目标、实际成果，上传立项书或填写无立项书说明。AI 只辅助提取背景和目标，需人工核实；实际成果自行填写。按部门规则确认审核范围，无立项书时逐项回答条件部门问题，HR 固定必审，仅跳过实际提交人本人的前置节点。申请后项目暂时冻结，由部门负责人按清单审核，全部通过后交该申请指定的总经办负责人终审。退回或申请人撤回后恢复编辑；批准后结项，形成固定报告，HR 及相关领导收到待阅通知。时间差异由系统自动记录，不再强制重复填写迟申请、超期申请说明。

结项管理统一查看申请和报告；旧报告入口自动跳转到该页面。报告可在系统内查看并导出独立 HTML。HTML 可离线阅读正文和图表；附件仍须通过系统或原平台权限访问。HR“确认已阅”不改变审批结果，也不表示已执行奖惩。

需要纠错时，由项目负责人申请重开并说明原因。批准后原报告标为失效但保留，新结项生成新版本。历史旧归档仅管理员可恢复；新结项不能借历史恢复入口解锁。

**模板状态**：四部分绿色模板和背景/目标/成果表单已接入，报告包含审核记录；历史申请按原快照版本渲染。详见 [结项与报备](21-项目结项推送人力资源部（奖惩报备）方案.md)。

## 八、飞书通知与手机使用

工作日个人汇总在北京时间 09:10、13:10 发送；项目群简报 09:00；周关键进展填写提醒在每周五 14:00 发送，节假日跳过，不顺延到周一或补班周末。提醒按项目和父子任务分级展示，项目负责人会收到 @ 提醒。节假日由系统日历配置决定。

审核通知按钮打开系统处理。审核完成后系统尝试将原卡片更新为已审核、已退回或已撤回；更新异步执行，失败会重试。旧消息没有可用消息 ID 或平台不支持更新时，可能无法回写，系统中的审核结果为准。

机器人支持查询自己的任务、项目进度、延期及待审事项；启用智能体时支持自然语言和追问。机器人查询不替你修改任务或审批。手机网页支持相应业务操作，仍按账号权限和网络可达性判断。

## 九、工作日报与审批历史

工作日报按北京时间的原始提交时间 created_at 汇总，默认上一个工作日；工作日期 work_date 单独显示，不能把补填误当成当天完成。网页仅 admin 或当前总经办接收人可看，普通 leader/dept_head 身份本身不授予权限。读取日报成功后按用户与日期记录已读，未读从首次可见日期开始，不依赖本机浏览器缓存。

在审批管理切换“待我审批、我已审批、我发起的、与我相关”，可按类型筛选、按项目展开。点历史记录查看当轮申请人、审核人、时间和结果；后续退回或重提不会把过去通过的那一轮改成当前状态。只读参与者和历史详情不显示可执行审批操作。

## 十、管理员与常见问题

| 问题 | 处理 |
|---|---|
| 已填写进展但不能验收 | 查看缺填周次及本条资料/无资料原因，不能用某周记录替代其他周 |
| 已完成但无法补资料 | 检查项目是否已归档或结项冻结，以及本人是否有维护权限 |
| 想编辑他人进展 | 仅进行中任务可编辑正文，由作者或有对应管理权限的人处理；已确认合理补填的记录须先处理确认状态，已完成任务不能直接编辑 |
| 定稿后不能改计划 | 发起变更；只有管理员可解除定稿，且不能绕过结项冻结 |
| 看得到项目却不能操作 | 查看权限与写入权限不同，结项/验收还要求指定身份 |
| 需要多人 HR 看报告 | 管理员配置 HR 阅览授权，授权不增加审批或代知晓权限 |
| 删除项目 | 仅管理员或项目负责人可删未定稿且未冻结的项目；先核对关联资料和历史留存 |
| 日历提醒不正确 | 管理员核对节假日/补班配置，日期规则按北京时间 |

更多规则见 [权限模型](03-权限模型.md)、[进展与资料](14-任务过程资料与每日进展强管控方案.md)、[结项与报备](21-项目结项推送人力资源部（奖惩报备）方案.md)。
